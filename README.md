# EyeSee website
Single static file (index.html). Fill the CONFIG block at the top of its script; see ../SETUP.md.
Features: landing + demo bubble, smart URL/keyword bar (opens the page in a new tab and asks the extension
to translate it), Supabase login/sign-up, 2-day trial status, Stripe Checkout button, AR/EN UI.
Local test: `python3 -m http.server 8080` in this folder, then open http://localhost:8080
